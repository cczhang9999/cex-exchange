# 2026-10-13

## 修复 Trade.vue 行情面板空指针崩溃

**现象**：`Trade.vue` 报 `Cannot read properties of null (reading 'bids')` (145/633)、
`(reading 'length')` (208)，以及 `/api/kline` 404。

**根因（三层）**：
1. `backend-v2` 的 `/api/orderbook`、`/api/trades`、`/api/klines` 在 gRPC 调用失败时
   返回 **HTTP 200 + `{code:500, data:null}`**（`internal/pkg/response/response.go` 的
   `Error()` 固定用 200 状态码）。前端 axios 不抛错，直接 `orderbook.value = data.data`
   把 ref 置为 `null`，模板随即崩溃。
2. 前端 `getKline` 请求 `/api/kline?period=`，但后端实际路由是 `/api/klines?interval=` → 404。
3. 最深根因：撮合引擎 gRPC 服务（`cex-exchange/cmd/grpc`，监听 `:50051`）未启动，
   `backend-v2` 配置 `client.exchange.addr = localhost:50051`，连接被拒 → 所有行情为空。

**改动**：
- `frontend/src/api/api.js`：`getKline` 改请求 `/api/klines`，参数 `period` → `interval`。
- `frontend/src/components/Trade.vue`：
  - `fetchOrderbook` / `fetchTrades` 增加 `code === 0` 与数据类型校验，失败时回退空数组/空对象。
  - `loadKlineData` 增加 `res.data.code === 0` 校验，`orderbook.value?.bids` 可选链。
  - 模板加固：`orderbook?.bids || []`、`orderbook?.asks || []`、`trades?.length || 0`、`:data="trades || []"`。
  - 新增 `tradeTime(row)`：兼容 REST 的 `timestamp`(秒) 与 WS 的 `created_at`(ISO)。
- `backend-v2/internal/server/server.go`：orderbook/trades/klines 三处 nil slice 归一为 `[]`，
  不再向前端吐 `null`。

**验证**：`go build ./...` 通过；`npm run build` 通过。

**待办**：启动撮合引擎 `cd cex-exchange && go run ./cmd/grpc` 才能看到真实行情数据。
